This is where an important point emphasized by many cybersecurity professionals comes into play: having a solid understanding of programming is essential. It allows us to read and understand scripts, identify insecure logic, and recognize potential security vulnerabilities

💡 Reviewing the script reveals basic Python libraries like subprocess for Git commands and urllib to communicate with the Gitea API

The primary job of the script is iterating through repositories marked as templates and placing copies into the staging directory

The critical logic lives inside the sync template function

The script executes git ls-tree to fetch all file paths inside the repository

Then it constructs destination paths like this:

target = os path join stage path filepath

Root Cause Analysis

The script trusts the filepath retrieved from Git without any path sanitization

The os.path.join function allows path traversal sequences like ../ to break out of the staging directory

Since the service executes with full root permissions an attacker gains complete filesystem access

An attacker creates a malicious template repository with payload file paths targeting system files like SSH authorized keys

When the synchronization service runs it executes git cat-file and writes the payload to arbitrary system paths

Exploit Flow

Gitea Template Repository —→ Path Traversal File Name —→ Arbitrary File Write as Root —→ Full System Compromise

💡 The following security vulnerabilities were identified:

  • Path Traversal: The file path is not properly validated.
  • Insufficient Input Sanitization: The application allows the use of ../ path traversal sequences.
  • Execution with Root Privileges: The script runs with root privileges, potentially allowing full system compromise.
  • No Rate Limiting: The functionality can be triggered repeatedly without any apparent rate-limiting mechanism.

The script reads the generated SSH public key and stores it as a Git blob. It then creates a custom Git tree containing .ssh/authorized_keys. To exploit the identified path traversal vulnerability, the script inserts multiple .. path components into the Git tree.

Finally, it creates a commit pointing to the malicious tree and sets it as the main branch. After pushing the repository to Gitea, the root-owned template synchronization service processes these Git paths, allowing the path traversal vulnerability to be triggered in a privileged context.
