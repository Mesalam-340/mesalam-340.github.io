PORT 21 FTP (ProFTPD 1.3.5)

I think I will give a look for my methodology.

Now we will do FTP Banner Grabbing, or simply manually connect to the FTP service and see how the server responds.

┌──(root㉿omar)-[/home/mesalam/Metasploitable3] └─# nc -nv 192.168.68.130 21 (UNKNOWN) [192.168.68.130] 21 (ftp) open 220 ProFTPD 1.3.5 Server (ProFTPD Default Installation) [192.168.68.130]

Now we know some things:

  • Port 21 is open, the FTP Server is named ProFTPD, its version is 1.3.5, and the server is ready for requests.
  • (ProFTPD Default Installation): This usually indicates that the server is running with default or near-default settings.

This is something that should catch the pentester's attention, because default installations sometimes contain insecure settings such as anonymous access, weak configuration, unnecessary features, default accounts, and weak permissions. However, a default installation doesn't automatically mean there's a vulnerability.

┌──(root㉿omar)-[/home/mesalam/Metasploitable3] └─# nmap -p 21 --script ftp-anon,ftp-bounce,ftp-libopie,ftp-proftpd-backdoor,ftp-vsftpd-backdoor,ftp-vuln-cve2010-4221 192.168.68.130 Starting Nmap 7.95 ( https://nmap.org ) at 2026-08-28 23:25 EDT Nmap scan report for 192.168.68.130 Host is up (0.00030s latency). PORT STATE SERVICE 21/tcp open ftp MAC Address: 00:0C:29:12:1B:CB (VMware) Nmap done: 1 IP address (1 host up) scanned in 21.49 seconds

We use this command when we find FTP on Port 21 and want to perform automated enumeration and vulnerability checks on the service instead of checking everything manually. The result here indicates that FTP is working on port 21 and is open, and the NSE scripts selected didn't yield a clear finding.
